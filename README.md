# Aeroplanes Project

Курсовой проект по работе с API, ООП, JSON-файлами и консольным взаимодействием.

Проект получает данные о самолетах в воздушном пространстве выбранной страны, преобразует их в объекты Python, сохраняет данные в JSON-файл и позволяет фильтровать/сортировать самолеты.

## Используемые API

В проекте используются два внешних сервиса:

- Nominatim OpenStreetMap API — для получения географических координат страны;
- OpenSky Network API — для получения информации о самолетах в заданных координатах.

## Реализованный функционал

### Работа с API

Реализован абстрактный класс `AbstractAPI`.

На его основе создан класс `AeroplanesAPI`, который умеет:

- получать координаты страны через Nominatim;
- получать данные о самолетах через OpenSky;
- обрабатывать ошибки при некорректных ответах API.

### Класс Aeroplane

Класс `Aeroplane` описывает самолет.

Атрибуты:

- `icao24` — уникальный идентификатор самолета;
- `callsign` — позывной;
- `origin_country` — страна регистрации;
- `velocity` — скорость;
- `altitude` — высота;
- `on_ground` — находится ли самолет на земле.

Также реализовано:

- валидация данных при создании объекта;
- строковое представление объекта;
- сравнение самолетов по скорости;
- сравнение самолетов по высоте;
- преобразование объекта в словарь;
- создание списка объектов из ответа OpenSky.

### Работа с JSON

Реализован абстрактный класс `AbstractSaver`.

На его основе создан класс `JSONSaver`, который умеет:

- добавлять информацию о самолете в JSON-файл;
- получать все сохраненные самолеты;
- получать самолеты по указанному критерию;
- удалять самолет из JSON-файла.

### Утилиты

Реализованы функции:

- фильтрация самолетов по стране регистрации;
- фильтрация самолетов по диапазону высоты;
- сортировка самолетов по высоте по убыванию;
- получение топ N самолетов;
- вывод списка самолетов в консоль.

### Консольное взаимодействие

В `main.py` реализована функция `user_interaction()`.

Пользователь может:

- ввести название страны;
- получить данные о самолетах;
- сохранить данные в JSON-файл;
- отфильтровать самолеты по стране регистрации;
- получить топ N самолетов по высоте;
- увидеть результат в консоли.
